# 🎓 Formação Full Stack — Jornada de Desenvolvimento

Este repositório centraliza minha trajetória de estudos dentro da formação **Full Stack**, reunindo cursos, projetos práticos e evolução técnica ao longo da especialização no curso do **Full Stack Club**.

O objetivo é documentar de forma organizada todo o processo de aprendizado, funcionando como:

* 📚 Registro estruturado da formação
* 🧪 Repositório de projetos desenvolvidos durante os cursos
* 📈 Acompanhamento da evolução técnica
* 💼 Base prática para consolidação profissional na área de tecnologia

---

## 🚀 Estrutura da Formação no Repositório

Cada curso realizado dentro do Full Stack Club é organizado em uma pasta própria, contendo seus respectivos projetos e documentação.

```text
Curso-FSC/
│
├── Code-Start/        → Fundamentos do desenvolvimento web / finalizado
├── React/             → Iniciado
├── Full-Stack/              → próximo
└── Full-Stack-Avançado/    → (futuro)
```

Essa divisão permite acompanhar claramente a progressão entre os níveis da formação.

---

## 📌 Sobre o Full Stack Club

O Full Stack Club é uma formação voltada à capacitação prática em desenvolvimento web, com foco na construção de aplicações reais e no domínio progressivo das tecnologias utilizadas no mercado.

A metodologia é baseada em:

* Aprendizado por projetos
* Construção de base sólida antes de avançar para frameworks
* Evolução gradual até arquitetura Full Stack completa

---

## 🎯 Objetivo da Jornada

Desenvolver domínio técnico nas seguintes tecnologias ao longo da formação:

* HTML, CSS e JavaScript (base sólida)
* React e ecossistema moderno de Front-End
* Integração com APIs
* Back-End com Node.js
* Banco de dados e persistência
* Arquitetura Full Stack
